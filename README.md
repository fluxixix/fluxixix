### 这个博客

[fluxixix.github.io](https://fluxixix.github.io) —— VitePress 起底，
主题是手搓的：hero 光晕跟随指针、光标粒子拖尾、明暗切换从按钮扩散、
列表滚动揭示；顶栏在首页往下滚时会收成一条浮动胶囊。
四个交互都做了降级，禁用 JS 时页面就是普通内容。
